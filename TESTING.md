# Проверка проекта

## Автоматические тесты

Тесты находятся в файле `test_app.py`

Запуск из папки проекта:

```bash
.venv/bin/python -m unittest -v
```

Тесты проверяют:

1. Главная страница открывается и содержит заголовок
2. В базе данных находится 50 приложений
3. На странице выводится 50 карточек и данные приложения МАКС

Ожидаемый результат - все три теста проходят, в конце выводится `OK`

## Проверка в браузере

1. Открыть главную страницу. Должны появиться карточки приложений
2. Нажать на карточку. Должна открыться страница этого приложения в RuStore
3. Нажать «Перейти в оригинальный RuStore». Должен открыться каталог RuStore
4. Открыть страницу на узком экране. Карточки должны поместиться по ширине экрана
5. Проверить иконки приложений. Для их загрузки нужен интернет
