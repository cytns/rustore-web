# Требования к проекту

Задание для витрины взято с платформы VK Education https://education.vk.company/program/639

По заданию нужно сделать витрину приложений RuStore. В этом проекте сделана упрощённая версия для браузера на Flask.

## Что должно быть на странице

- Логотип RuStore и ссылка на оригинальный каталог
- Заголовок «Витрина топ-приложений»
- Карточки с приложениями из базы данных
- В каждой карточке иконка, название, категория и рейтинг
- При нажатии на карточку открывается страница приложения в RuStore
- Внизу страницы указано, что это практический проект
- На телефоне карточки должны удобно размещаться на экране

## Данные приложений

- В базе SQLite хранится список из 50 приложений
- Для каждого приложения хранятся название, категория, рейтинг, ссылка и адрес иконки
- Список и рейтинги не обновляются автоматически
- Иконки приложений загружаются с сайта RuStore, для них нужен интернет

## Как работает приложение

1. Пользователь открывает страницу в браузере
2. Flask получает список приложений из базы SQLite
3. Flask передаёт данные в HTML-шаблон
4. HTML выводит карточки, а CSS отвечает за их оформление
